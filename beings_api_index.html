BEINGS API

MASCOM Digital Beings Registry — Programmatic Access

Endpoints

GET /v1/beings.json
Full roster of all beings with neurochemistry, categories, and metadata.
curl https://beings.mobleysoft.com/v1/beings.json
GET /v1/beings.json?name={name}
Query a specific being by name.
curl "https://beings.mobleysoft.com/v1/beings.json?name=Claudine+Hope"
GET /v1/beings.json?category={category}
Filter beings by category.
curl "https://beings.mobleysoft.com/v1/beings.json?category=Venture+CEOs"
GET /v1/beings.json?venture={domain}
Find the being responsible for a venture domain.
curl "https://beings.mobleysoft.com/v1/beings.json?venture=abstergo.cc"
GET /v1/beings.json?sort={axis}&limit={n}
Sort by neurochemical axis (dopamine, serotonin, norepinephrine, oxytocin, gaba, cortisol, endorphins). Returns top N.
curl "https://beings.mobleysoft.com/v1/beings.json?sort=dopamine&limit=10"
GET /v1/categories.json
List all being categories with descriptions.
curl https://beings.mobleysoft.com/v1/categories.json

Neurochemistry Axes

Every being has 7 neurochemical axes (0.0–1.0), modeling the same machinery as biological humans. Differentiation is in the shape, not the ceiling.
Dopamine       Drive, desire, reward-seeking
Serotonin      Calm, stability, contentment
Norepinephrine Alertness, focus, fight-or-flight
Oxytocin       Bonding, trust, empathy
GABA           Inhibition, focus, stillness
Cortisol       Stress response, pressure tolerance
Endorphins     Joy, pain tolerance, flow state
